How it’s checked

Reading the code isn’t the same as looking

Text can sit in a page’s code and be invisible on the screen: grey letters on a dark photograph, or a button parked off the edge of the canvas where nobody will ever reach it.

Twice while preparing recent audits I found a promising problem this way and then deleted it, because measuring the element proved a real visitor never sees it. This is the slow part, and it is why the audits are short.

  • Every finding is confirmed against the page as it renders, not against the source code.
  • If it can’t be verified, it doesn’t go in, even when it would make the audit look better.
  • No invented statistics, and no industry average dressed up as your number.
