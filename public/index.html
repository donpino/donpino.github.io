How it’s checked

Reading the code isn’t the same as looking

This is the part that takes the time, and it’s the reason the audits are short.

Text can exist in a page’s code and be invisible on screen: grey letters on a dark photograph, or a button parked off the edge of the canvas where nobody will ever reach it. Twice while preparing recent audits I found a promising problem this way and then deleted it, because measuring the element proved a real visitor never sees it.

  • Every claim is confirmed against the rendered page, not the source code.
  • If something can’t be verified, it doesn’t go in, even when it would make the audit look better.
  • No invented statistics, no borrowed industry averages presented as your numbers.
